## Completed empirical outputs

questions. It completed 295,568 rotation scores, 31,360 averaged vectors, 160
analysis settings, 10,240 candidates and 2,000 frozen-fit resamples.

## Result archive and reproduction

The separately delivered archive is:

```text
outputs/xwvg_reference_selection/XWVG_Utility_Results_20261107.zip
outputs/xwvg_reference_selection/XWVG_Utility_Results_20261107.zip.sha256
```

Its SHA-256 is
`454afea8e5d9257119bc396eecd3dd057d32cd248081645c2624aae2bb3e7814`.
The extracted `XWVG_Utility_Results/` directory contains the result tables, figures,
reports, inputs, code snapshot, provenance, audits, `DELIVERY_MANIFEST.json`, and
`reproduce_analysis.py`. Model weights and environments are not bundled. The
archive is not uploaded to Git as part of the source commit.

The original run recorded repository revision
`ebd16e37fca696328402e4bdc2e035a507f8c5bf` plus exact hashes of the then-uncommitted
experiment source. The source commit publishes that implementation without
rewriting the completed run's provenance or archive.

The bundle helper requires its `--repo-root` checkout at that original revision.
After committing the source, use a separate clone or detached worktree at the
recorded revision; the helper imports the bundled experiment source and uses
that checkout for the historical repository inputs. Pass a new `--output-root`.
By default the helper verifies the bundle and prints the CPU command; `--run`
executes it. Running the current Git source also requires a fresh output
directory because the Git revision is part of run identity. Do not resume or
overwrite the completed output directories under a different identity.

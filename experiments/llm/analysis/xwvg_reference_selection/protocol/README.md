# XWVG 用途补充实验：交给 Codex 的执行包

## 要回答的问题

同样只能选择两个或三个同伴模型时，考虑它们**一起使用的效果**，能否比挑选**分别最像目标的几个模型**，更准确地复现目标模型在新题目上的回答概率？

这个实验直接检查：论文分析得到的模型关系，是否能够改善一个具体的选择。每个目标单独选择同伴，范围限定为本文实际记录的选项概率。

## 交给 Codex 的入口

把本压缩包提供给能够访问原实验目录的 Codex。让它先读 `CODEX_TASK.md`，再按任务中的顺序实施和运行。

本包包含**实验方案、真实代码位置、固定配置、数据预检工具、稀疏 TV 求解器参考实现和数值检查**。真实数据实验尚未执行。参考实现通过的是构造数据检查，不能把这些检查当成论文的新实验结果。

## 已经核对的代码

核对了论文给出的匿名仓库，下载快照共有 521 个文件。快照来源及关键文件 SHA-256 位于 `evidence/source_manifest.json`。

代码中最有用的发现：V2.3 的 `assemble_permutation_scores()` 已经把循环选项排列平均后的**完整选项概率向量**保存在 `permutation_averaged_semantic_scores.parquet` 中。它并不只保存正确答案的一个概率。因此，优先直接复用这一缓存，使用与正文主要实验相同的 clean / maximum-stress 条件。

这些逐题缓存没有包含在公开仓库中，需要从原实验工作目录读取。公开的 1,600 行 vector results 是已经拟合过的汇总结果，不能代替逐题向量。`make analysis` 也只重建旧的汇总表，不会执行本次新增实验。

## 固定的主实验

- 全部八个原有模型分别作为目标。
- 两种扰动分别进行，沿用十次原有问题划分。
- 主比较：最多两个同伴；次比较：最多三个同伴。
- 一个和七个同伴作为参照与实现检查。
- 三种选法：按组合效果、按单个相似度、均匀随机选择的精确平均结果。
- 三种方法均使用同一个 TV 拟合目标和同一种固定凸组合。
- 主结果是未参与选择的题目上的 TV；辅助结果是首选选项一致率。
- 选择、拟合和并列处理均不能看评估题目的目标输出。

主实验使用**循环排列平均后的完整选项概率、两个端点**。每题 clean 权重为 1/2，三个最大扰动实例各为 1/6。canonical 五强度实验仅作为单独标记的可选补充，不能在缓存缺失时悄悄替代主实验。

## 运行要求

缓存齐全时，主实验只需要 CPU，不需要再次调用模型或生成回答。完整点估计需要检查 10,240 个候选，其中 9,120 个是非单模型拟合；不能把它说成几次简单回归。任务要求先做固定的小规模计时，再继续全部目标，并保存可恢复的中间结果。

默认提供 2,000 次**固定已选子集和已拟合权重**的问题重采样，明确标为描述性区间。默认不做 1,000 次全流程重新选择和拟合，那会额外引入约 912 万次非平凡拟合。

原始数据缺失时，Codex 应完成能完成的代码与数值检查，生成确切缺失清单。不能用汇总表构造假的逐题输出，也不能把未运行的实验标为成功。

## 结论怎么写

只有评估集上的改善才支持用途主张。拟合集上的组合最优是选择规则本身保证的，不能作为新发现。必须保留全部目标上的正、负和接近零的结果。模型数量预算不能直接解释为降低运行成本；选择后的概率近似也不等于完整模型能力可以替换。

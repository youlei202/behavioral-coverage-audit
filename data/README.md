# Evidence and derived data

`frozen/llm/`, `frozen/vision/`, `frozen/traffic/`, and `frozen/bert_legacy/` preserve the supplied archived evidence byte-for-byte. Small unused synthetic/legacy controls from the same paper package remain explicitly under `frozen/synthetic_legacy/`; they are not relabeled as modern-LLM observations.

`manifests/input_sha256.tsv` records the original archive/member, stage, size, SHA256 and role for all 77 replay inputs, including two archived vector-analysis source files kept under `experiments/`. `data_map.json` gives their former paper-relative paths. `input_schemas.json` freezes every CSV's column order and row count.

The 1,600-row vector Parquet is retained with its successful completion marker. Its scalar-column CSV is a documented lossless derivative; nested weights remain only in the original Parquet. Normal replay independently checks the CSV against a standard Parquet decoder before arithmetic replay.

`generated/` is disposable and regenerated by `make tables`. Expected output hashes are in `paper_expected_outputs.tsv`. Generated output baselines are verification targets, never classified as original scientific inputs. `make clean` removes generated outputs and compiled artifacts but does not touch frozen evidence.

Large inference design files and cached analysis artifacts are referenced through separate external manifests. Set `BEHAVIORAL_COVERAGE_RAW_DATA` for cached analysis replay. Model caches are external and are not copied into the source repository.
